# Timezone Globe Web App

A simple and attractive world-time website to compare time across places.

## Live Website

Open the deployed site here:

https://ameyarajwade7.github.io/Timezone/

## How To Access Locally

1. Open a terminal in this project folder.
2. Run:

```powershell
npx --yes serve -l 5500 .
```

3. Open:

http://localhost:5500

## Basic Usage

1. Search for a city/place in the search box.
2. Click Add or press Enter.
3. Use the time bar on any card to scrub time and compare places.
4. Click Reset Live to return to real-time mode.

## Tech

- HTML
- CSS
- JavaScript (vanilla)
- Browser Intl APIs for timezone formatting
- Open-Meteo geocoding API for city search
